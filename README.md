# Ruta Segura — Maraton 2026 (Grupo SmartCode)

Panic-alert system for women in nocturnal public space (SDG 5, 11, 16).

- `api/` — Flask REST API (MVC), PostgreSQL on Azure, SQLite locally.
- `web/` — React + Vite guardian portal (live map), served by the API in production.
- `mobile/` — Expo app with the SOS trigger.
- `docs/` — architecture, AI usage and pitch (Spanish).
